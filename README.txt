ARYA ENTERPRISES — FIRST WEBSITE VERSION

Files:
- index.html   main website
- styles.css   responsive design
- script.js    mobile menu, reveal animation, portfolio lightbox
- assets/      images taken from the supplied company profile PDF

How to run:
1. Keep the folder structure unchanged.
2. Double-click index.html, or open it in a browser.
3. For local development, VS Code + Live Server can be used.

The first version is intentionally a static website. Contact links use the phone/email details shown in the supplied profile. Portfolio/client imagery is retained from the profile rather than inventing new client information.
